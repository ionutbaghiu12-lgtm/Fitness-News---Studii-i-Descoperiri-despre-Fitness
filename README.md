# Fitness-News Studii si Descoperiri despre Fitness
Despre Proiect
Aceasta este o miniaplicație Android dezvoltată ca proiect de semestru la disciplina Calcul Mobil. Obiectivul este parcurgerea unui ciclu de dezvoltare ce include planificarea, implementarea incrementală și lucrul în echipă pe un repository comun. Funcționalitățile principale, conform cerințelor, includ afișarea unei liste de elemente (știri/studii), navigarea către un ecran de detaliu, salvarea de date pe dispozitiv și preluarea de date dintr-un API extern. Aplicația este proiectată să ruleze pe un emulator sau pe un dispozitiv fizic.
De ce am ales tema
Proiectul se încadrează în categoria de teme „news”. Tema a fost selectată deoarece agregarea și prezentarea articolelor sau studiilor recente despre fitness se pliază perfect pe cerințele tehnice obligatorii: listarea articolelor, detalierea fiecărui studiu și extragerea informațiilor actualizate din surse externe.
Tehnologii și Componente Utilizate
Mediu de dezvoltare: Android Studio.

Controlul versiunii și Colaborare: GitHub, utilizat pentru lucrul în echipe de 2-3 studenți și pentru evidențierea contribuțiilor vizibile (commit-uri) ale fiecărui membru.

Preluare date API: Biblioteci specifice (ex. Retrofit sau Volley) pentru îndeplinirea cerinței de preluare a datelor dintr-un API extern.

Stocare locală: Soluții de persistență (ex. Room Database, SQLite sau SharedPreferences) pentru salvarea de date pe dispozitiv.

Interfață Utilizator: Componente Android (ex. RecyclerView, Activity/Fragment) pentru implementarea listei de elemente și a ecranului de detaliu.
